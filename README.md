# MaxOS Engine

**Version:** 0.1.0 — playable browser prototype

MaxOS Engine is an original FNF-style rhythm-game prototype. It is inspired by four-lane rhythm gameplay, but it is not Psych Engine and does not include copyrighted FNF art, music, or source code.

## Try it
Open [index.html](./index.html) in a modern browser. No installation, server, API key, or external assets are required.

## Controls
- **Arrow keys** or **A / S / W / D** to hit the four lanes.
- You can also click or tap a lane.
- **Escape** pauses the round; starting again restarts it.

## Prototype features
- Four-lane falling-note gameplay
- Random demo chart at 110 BPM
- SICK / GOOD / OK / MISS judgments
- Score, combo, accuracy, rating, health bar, and hit effects
- Restartable 45-second demo round

## Known limitations
- Demo chart is randomly generated each round.
- No music playback or audio-clock synchronization yet.
- No chart editor, custom song import, mod loader, characters, stages, Lua, or native desktop build yet.
